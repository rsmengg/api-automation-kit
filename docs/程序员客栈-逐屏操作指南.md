## 第 0 步（**先做，3 分钟**）：确认你能过签约审核

程序员客栈不是注册完就能接单，要过「签约开发者」审核。审核是人工的，资料不齐会被驳回，驳回一次要等 3–7 天再提。

| 审核项 | 要求 | 你先自查 | 不满足怎么办 |
| --- | --- | --- | --- |
| 年龄 | 年满 24 周岁 | 你自己知道 | 硬性，没得绕 |
| 学历 | 需上传学历证明，时间线要合理 | 学信网能查到 | 学信网查不到就先去办认证 |
| 正式经验 | 1 年以上（你远超） | ✅ | — |
| 互联网公司经历 | 需 3 年正式工作经历，跳槽不超过 4 家 | 看你的履历 | 不足就走「码市 / 电鸭 / V2EX」路子 |
| 工作证明 | 工牌 / 企业邮箱 / 在职或离职证明 / 社保记录 / 企业认证钉钉，任选 | 手边有没有 | 缺的现在去开，**别等提交时才发现** |
| 专业社区影响力 | 建议绑定 GitHub / GitLab / 博客，仓库里要有可看的开源项目 | **你已经有了** | 测试岗本来可免绑，但你有更好 |
| 代表作品 | **不少于 3 个**，每个要有有效链接 + 详细描述 + 运行截图 | 见下文第七节 | 最多，也最重要 |

**给你的作品凑数方案**（3 个正好，别凑第 4 个）：

1. `api-automation-kit` —— 就是本仓库，链接 `https://github.com/rsmengg/api-automation-kit`
   描述照抄：「Pytest + Allure 接口自动化回归套件，`--base-url` 切环境，失败自动落盘 request/响应/trace，
   GitHub Actions 提交即跑。Mock 服务自带，clone 下来一条命令跑通，不需要准备环境。」
2. 健康数据仪表盘原型（你做过的那个）—— 上传截图 + 演示图链接
3. 你写过的另两个开源/内部工具里挑一个能公开讲清的（接口测试平台、压测脚本、订单批量工具都行）

> 第 3 个作品**没有就不硬凑**。审核看的是"有 3 个能讲清楚的"，不是"必须有 3 个上线产品"。
> 实在不够，就把第 1 个拆成两条写（"接口自动化套件" + "压测与性能报告模块"）——同一个仓库拆成两个服务条目，
> 这在平台是允许的，但**第 6 节那份描述必须自己重写一遍，别直接复制**，复制痕迹很重。

## 第 2.5 屏 · 教育经历（**非科班怎么填**）

### 结论先给：专业那栏填**真实的**，一个字都别改

签约审核要**学历证明**（学信网备案表 / 毕业证），审核人会拿你填的专业去比对证书上的专业名。

- 填了真专业 → 对得上，过；**专业是计算机还是别的，审核本身不问**
- 填了"计算机科学与技术" → 证书上不是这个名字，**比对失败。而且是"填无效信息"**，按平台自己那句红字警告，
  **不二次审核，严重的直接拉黑不能接单**——这是一次性dead end，比被驳回一次严重得多

**平台卡的是"学历真实 + 履历真实"，不是"专业对口"。** 非科班不是门槛，假专业才是。

### 这一屏四栏怎么填

| 字段 | 填什么 |
| --- | --- |

| 专业 | **和毕业证/学信网一字不差**（非科班就照实填，这一栏不会因为你填了自己专业就驳回） |
| 学历 | 真实（本科） |

### 主动交代非科班，放在哪、怎么写

**别在学历栏里找补**（改专业名＝假信息）。放到**个人简介 / 技能标签以外的自我介绍**里主动讲，效果完全不同：

> 非科班出身，本科读的是非计算机专业，工作后自学 Python 转入软件测试方向；靠实际项目练出来的接口自动化能力，不靠科班出身背书。

**为什么主动说反而加分**：
1. 审核人迟早会从你的公司履历里看出来，**被他发现 vs 你自己交代**，观感差一个量级
2. 测试岗非科班是常态，审核人对这个不敏感；**真正让他皱眉的是"专业写了计算机的但证书不是"**
3. 你手上有一个带 CI、能跑通的完整套件——**这比一个科班但没作品的竞争者硬**

### 三处硬伤自查（过了这两处，非科班不构成问题）

1. **学历时间线和工作经历连不上** → 中间那段空窗被反复追问。如果存在空窗（例如毕业后先做了别的工作），
   在「工作经历」里**补一条真实且体面的过渡**（比如"某零售 ERP 系统实施/运维"），**别编造公司名**
2. **学历证明交不上**（学信网查不到/毕业太久查不到） → 先去学信网办《学历证书电子注册备案表》，
   没有这个，审核一定卡住
3. **投递方向和专业跨度太大**（比如本科是文学，却投"Go 后端架构"） → 只投**测试 / 自动化 / 质量保障**类，
   这是你最贴的方向，专业跨度看着也不违和

**这是你现在唯一必须自己拍板的事**，别的我都能替你做。

| --- | --- | --- | --- |
