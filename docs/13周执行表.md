# 13 周执行表（我方推进 / 你只做三件事）

> 目标：第 13 周月化 ¥3,000–8,000（结构：3–5 个小单 + 1 个长期客户）
> 分工：**除第 4 列的动作外，全部由我推进。**

## 每周你只做这三件

1. 周一：把上周我给你的**投递文案**复制发出去（每天 1–3 条，10 分钟）
2. 有人回消息：把聊天记录转我，我来写方案 / 报价 / 英文提案
3. 周五：确认收款节点，收到钱就行

## 排产

| 周次 | 我来做 | 你要动的 |
| --- | --- | --- |
| W1–W2 | 开源 `README.md` 包装、四套 profile 文案、跑通本地 mock 与 CI、出第一条投递名单 | 只看一眼 README 满不满意，不满意我改 |
| W3–W4 | 每日投递名单 + 话术（累计 40 条）、整理《接口风险清单》模板、谈下第 1 单 | 每天发 1–3 条，回复我给的候选人 |
| W5–W6 | 交付第 1 单（压测脚本 or Monkey or 单接口自动化）、产出复用模板库、写 2 篇内容帖 | 收首付、给客户一句"干得挺快" |
| W7–W8 | 提价到 ¥25–35/h、把交付物抽象成可复用模板、发 2 篇内容帖挂接单入口 | 接第 2 单 |
| W9–W11 | 谈包月客户（目标 1 个）、出《月度回归报告》样例、开简历/面试辅导咨询 | 每周投 5 条定向私信 |
| W12–W13 | 结算、复购跟进、复盘：哪条渠道来的单最便宜，砍掉它 | 收尾款；决定下一季度主攻哪条 |

## 止损线

- **W6 还没出第一单** → 立刻切闲鱼/淘宝卖脚本模板（¥99–499/单，零沟通）先破零，
  同时把 profile 里的案例换成自己跑出来的真实数据。
- **W9 还没人回** → 说明渠道选错，转 Upwork 英文单（需求量大、时薪高、客户不砍价）。
- **W13 月化 <¥3,000** → 不追加投入，转"接单 + 简历辅导"双轨，先稳住现金流再谈增长。

## 不碰的东西（红线）

公司代码、公司数据、生产环境接口、公司电脑与账号、任何可还原甲方身份的信息。
所有交付示例一律脱敏为"某零售 ERP / 某电商中台"。
