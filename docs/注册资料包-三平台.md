# 注册资料包（按优先级排序，照抄即可）

> 原则：**先注册不花钱的，再注册要实名的。** 实名要上传身份证，别在还没决定干这行的时候交出去。

## 优先级与时间轴

| 优先级 | 平台 | 什么时候开 | 为什么要先开它 | 首月目标 |
| --- | --- | --- | --- | --- |
| P0 | GitHub | 第 1 周，2 分钟 | 所有平台的作品集链接都得挂它，不注册后面全卡住 | 仓库公开 + README 绿灯徽章 |
| P1 | 闲鱼 | 第 1 周同步开 | 零门槛、零抽成，当天就能挂出第一个 ¥99 商品破零 | 出 1–3 单小单 |
| P2 | 程序员客栈 / 码市 | 第 2 周 | 国内出单主力，客户有预算，抽成 10–20% 但单子大 | 谈下 1 单 ¥2k–4k |
| P3 | Upwork / Fiverr | 第 4 周 | 英文单不砍价、时薪高，是提价通道，不是起步通道 | 发 10 条提案，拿 1 个面试 |

**别一上来就冲 Upwork。** 你第一单的价值是"评价"，不是"单价"。第 6 周之前，Upwork 只当储备。

## P0 · GitHub（作品集地基）

**注册步骤**：github.com → Sign up → 邮箱 + 密码 + 用户名 → 收验证邮件点链接。

**用户名（选一个，改过一次就别再改）**

| 备选 | 说明 |
| --- | --- |
| `qa-auto-kit` | 直白，一眼知道是测试套件 |
| `devinspect` | 测开味道，短，好念 |
| `api-regression` | 偏接口自动化，客户搜索友好 |

别用中文拼音，别带年份。用户名会被当成门面，客户点进 README 就是在决定要不要给你报价。

**建完立刻做的三件事**
1. 仓库名 `api-automation-kit`，选 **Public**
2. 本地 `git push -u origin main`
3. README 顶部加 CI 徽章（`.github/workflows/ci.yml` 已经写好，push 后徽章自动亮绿灯）

**个人主页**：把 README 里的仓库链接贴进 GitHub 简介，方便别的平台 profile 往回引流。

## P1 · 闲鱼（当天破零）

不需要什么技术动作，本质是买"成交手感"。

**要填的**

- 标题：`自动化测试脚本定制 接口自动化搭建 压测报告`（30 字内，堆关键词）
- 一口价：**¥99**（别标"议价"，闲鱼标议价的买家砍价砍得最狠）
- 描述：直接写"交付 Pytest+Allure 可执行脚本 + 一份 5 分钟跑通的说明，接口自己给或用我给的 demo 环境"
- 类目：IT 服务 / 软件开发

**目的不是靠它发财**，是让你第 1 周就有钱进账、有买家对话、敢报价。第 6 周如果主线出单了，闲鱼直接下架。

## P2 · 程序员客栈 / 码市（出单主力）

### 程序员客栈

**注册**：程序员工客栈.com → 开发者 → 注册 → **实名认证（上传身份证 + 人脸）**。这个躲不掉，认证不过不能接单。

**要填的每一栏**

| 栏目 | 填什么 | 坑 |
| --- | --- | --- |
| 技术栈标签 | Python、Go、接口测试、自动化测试、性能测试(JMeter)、MySQL、CI/CD | 全勾不如只勾最硬的，勾多了系统推你不擅长的单 |
| 开发经验 | 5 年 | 别写 10 年，一问细节就露 |
| 期望时薪 | 首月 **¥60–80/h** | 第 7 周起提到 ¥100–120/h；平台抽成约 20% |
| 可接服务类目 | 接口自动化框架搭建、性能测试、测试开发、Go 接口开发 | 前两个是主力，Go 用来拉高单价 |
| 自我介绍 | 见下方文案 | 别写"热爱技术"，写交付物 |
| 作品/案例 | 贴 GitHub 仓库地址 | 这一步必须能给出链接，没链接不认证得过 |

**自我介绍文案（可直接复制）**

> 专注接口自动化与性能测试 6 年，交付过零售 ERP、电商中台两类中台系统的回归体系。
> 技术栈 Python + Pytest + Allure + JMeter + Go，能把"人工点一遍接口"改成一条命令跑完，
> 失败自动落盘 request/响应/trace，接入 Jenkins 或 GitHub Actions 提交即跑。
> 交付包含：用例目录规范、Allure 报告、CI 流水线、《用例维护手册》和一份《接口风险清单》。

**码市（Coding）**：流程一样，区别是**悬赏制**——客户发布需求，你自己报价抢单。注册后先把上面的自我介绍贴进个人简介，再去"DevOps/测试"类目里挑悬赏单。

## P3 · Upwork / Fiverr（提价通道）

### Upwork

**注册**：upwork.com → Sign up。**直接用 GitHub 账号登录**，省掉填表。

- **身份认证**：身份证 + 视频验证，第 4 周能做完就够，早做早好
- 时区：UTC+8，别乱填，提案里会被问
- 时薪首月：**$15/h**，第 8 周提到 **$25/h**，第 12 周 **$35/h**
- Call to action：每天 2 条提案，Upwork 每月给 10 个免费 Connects，每条提案花 1–2 个，别浪费

**Freelancer profile 三栏**（英文，见《接单资料包-国内.md》里的完整英文提案模板）

- Title：`API Regression Automation (pytest + Allure) & Load Testing (JMeter)`
- Overview：第一句必须写"我让接口回归从 1.5 人日变成 6 分钟"，再写技术栈
- Skills：Python, pytest, API Testing, JMeter, Go, CI/CD, MySQL

### Fiverr（Gig 制，值得单独花 1 小时）

一个 Gig = 一个商品。建 3 个：

| Gig | Basic | Standard | Premium |
| --- | --- | --- | --- |
| 接口自动化用例 | $30 | $100 | $300 |
| 压测脚本 + 报告 | $30 | $90 | $250 |
| Go 接口开发（小） | $40 | $120 | $350 |

每个 Gig 有 5 个必填：Gig 标题 / 分类 / 搜索关键词 / 套餐描述 / FAQ。**关键词填测试/自动化/QA/Regression/Performance**，Fiverr 的搜索流量全靠它。

## 红线（不论哪个平台）

- 不提供公司代码、数据、接口文档、环境地址

- 实名材料只交给平台自己的认证页，别发微信、别发邮件附件
- 甲方身份一律表述为"某零售 ERP / 某电商中台"，不提中免和真实客户名
